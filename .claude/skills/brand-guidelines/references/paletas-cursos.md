# Paletas por curso (manual, sección 2.3)

Cada curso tiene un color propio en 5 tonos (100% → 20%). Úsalos para diferenciar piezas por curso en redes y web. El amarillo, negro y blanco institucionales siguen presentes (logo, pastillas, pie). El color del curso domina el fondo o los acentos, no reemplaza al logo.

| Curso | 100% | 80% | 60% | 40% | 20% |
|---|---|---|---|---|---|
| Python | #009cfe | #33b0fe | #66c4fe | #99d7ff | #ccebff |
| Excel | #2daf73 | #57bf8f | #81cfab | #abdfc7 | #d5efe3 |
| Inteligencia Artificial | #072b4f | #395572 | #6a8095 | #9caab9 | #cdd5dc |
| Marketing | #8100c2 | #9a33ce | #b366da | #cd99e7 | #e6ccf3 |
| Ofimática | #f16621 | #f4854d | #f7a37a | #f9c2a6 | #fce0d3 |
| SQL | #7dba00 | #97c833 | #b1d666 | #cbe399 | #e5f1cc |
| Diseño Gráfico | #df245a | #e5507b | #ec7c9c | #f2a7bd | #f9d3de |
| Inglés | #d80027 | #e03352 | #e8667d | #ef99a9 | #f7ccd4 |
| Power BI | #f5d755 | #f7df77 | #f9e799 | #fbefbb | #fdf7dd |

Nota: en el PDF, el valor RGB de Python 100% figura como "R255 G156 B254", pero es una errata. El HEX correcto es #009cfe (R0 G156 B254).

Cursos que no están en la tabla (Comercio Exterior, Aduanas, Importaciones, AutoCAD, Revit/BIM, SketchUp, etc.) no tienen color asignado. Usa la paleta institucional (amarillo/negro/blanco). Para cursos técnicos, las piezas del manual usan azules o el color de la herramienta como fondo. Indica al usuario que el color es una propuesta y que lo confirme con el área de Diseño y Marca.

## Uso en CSS

```css
:root { --curso: #2daf73; --curso-80: #57bf8f; --curso-20: #d5efe3; } /* Excel */
```
